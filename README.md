# 🍽️ Online Menu

A modern, fast, and multilingual digital menu built with React.

The goal of this project is to provide restaurants with a simple and intuitive QR Code menu that offers a great experience for customers from different countries.

## Features

- 🌍 Multi-language support
- 📱 Responsive design
- 🔍 Product search
- ❤️ Favorite products
- 🖼️ Image preview
- ⚡ Fast performance
- ♿ Accessibility-focused

## Tech Stack

- React
- React Router
- Vite
- JavaScript
- CSS

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

To access the project from another device on the same network:

```bash
npm run dev -- --host
```
